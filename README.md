## 🧮 Real-Time Conversational AI & KaTeX Mathematical Rendering

All 5 web applications are powered by the **Cloud Turbo Groq AI Engine** (`js/chat-engine.js`), operating with zero terminal and zero local software installations required:

### 1. Ultra-Fast Cloud Inference
- **Performance**: Streams at **>1,400 tokens/second** with **~310ms time-to-first-token** via Cloud Turbo API (`qwen/qwen3.8-27b`, `groq/compound-mini`, `openai/gpt-oss-20b`).
- **Autonomous Multi-Candidate Fallback**: If a selected model reaches rate limits, the engine immediately cascades down backup models without dropping connection.
- **Offline Mode**: Includes an instant typewriter neural simulator pre-grounded in `PRISM_MASTER_KNOWLEDGE` for 100% offline functionality.

### 2. Native KaTeX LaTeX Mathematical Formula Typography
Both visitor chat inputs and AI responses natively render complex LaTeX mathematical formulas into publication-quality typography using **KaTeX**:

* **Block Math Equations** (`\[ ... \]` and `$$ ... $$`):
  $$\boxed{G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}}$$
* **Inline Formulas** (`$ ... $` and `\( ... \)`):
  Renders variables like $\mu, \nu$, vectors $\vec{v}$, and loss functions $\mathcal{L}_{\text{BCE}} = -\frac{1}{N}\sum y_i \log(\hat{y}_i)$ seamlessly inline.
* **Resilient Fallback**: If internet connectivity is interrupted, a built-in mathematical symbol and sub/superscript parser formats formulas gracefully until KaTeX re-syncs.
